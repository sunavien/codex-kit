# 归档聊天清理实现计划

本次交付可安装的 Python CLI，命令名为 `codex-kit`。依据本次会话需求，按归档时间批量清理聊天，提供列表、统计、预览、备份与恢复。默认使用 `CODEX_HOME`，并允许显式指定目录。使用 Python 标准库读取 SQLite，调用官方 `codex delete --force UUID` 完成删除。

## 验收与任务

1. `storage.py` 读取会话和父子关系，探测数据库结构和压缩会话文件。测试使用临时 SQLite 数据库，覆盖归档时间边界、缺失归档时间、压缩文件、无数据库和未知结构。
2. `cleanup.py` 生成完整删除计划。仅选择归档超过指定天数的聊天，跳过置顶、文件缺失和包含不合格后代的聊天。测试验证连带删除范围、去重和计划生成期间零写入。
3. `cleanup.py` 执行备份、逐项重新核对、官方删除及结果验证，维护操作日志。异常停止并保留成功与失败记录。测试通过隔离的假 Codex 可执行程序和真实 SQLite 验证边界，另使用本机 Codex 在临时目录运行集成验证。
4. `cli.py` 提供 `list`、`stats`、`prune --days N --dry-run`、交互确认和 `--yes`。提供 JSON 输出，非交互删除需要 `--yes`。`restore` 只恢复明确选择的备份批次并检查冲突。
5. 更新 README，验证安装入口、命令帮助、完整测试、隔离集成场景和真实目录只读预览。检查 diff 与需求覆盖。

## 实现选择

- Python 3.11+ 和标准库，不增加运行时依赖。
- 时间单位为连续的 24 小时，使用严格小于阈值比较。
- 任何真实清理需由用户另行调用 CLI。本轮开发使用临时数据验证删除。
- 原生删除的连带影响及恢复范围以官方 0.146.0 源码核实结果为准，必要变更记在下面。

## 执行记录

- 仓库基线只有 README 与 Apache-2.0 许可证，无现有代码或测试。
- 本机 CLI 为 0.146.0，存在 delete 和 --force 参数。
- 本机会话存在 .jsonl.zst 格式，路径解析必须兼容压缩文件。

## 裁决与验证

- 官方 0.146.0 的 `thread_delete.rs`、`thread-store/src/local/delete_thread.rs` 和 `state/src/runtime/threads.rs` 已核实。父会话删除包含 spawn 后代，会清理会话文件、名称索引、历史投影、日志、记忆、目标和状态行。
- 删除前检测 CLI 是否提供 `delete --force`，存储通过必需字段及父子关系表探测。实际验证版本为 0.146.0。恢复采用批次快照的选中行合并，遇不同记录拒绝覆盖。
- 恢复按数据库提交，支持相同记录重复执行。会话文件先写临时文件再原子创建，避免磁盘满留下半份文件阻塞重试。
- 使用 Python unittest，先验证缺少实现导致失败，再验证实现通过。新增内容覆盖 30 天边界、后代资格、压缩文件、执行前变化、部分失败、备份校验、恢复冲突与中断重试。
- 原生 CLI 集成已在临时目录验证父子两条聊天的删除和恢复。真实数据仅执行只读预览。
- 外部 Codex 进程不受本工具锁协调，操作仍有检查与删除间的竞争窗口。使用说明要求恢复前关闭 Codex，并建议清理前关闭其他 Codex 进程。

官方实现依据为 tag `rust-v0.146.0`，commit `e363b08c9175ac1cbe5893615dd2cb9ddf95043b`。

- 目录路径文件名以另一 UUID 结尾的历史记录会被跳过。官方 `matching_rollout_file_name` 同样要求 UUID 后缀匹配，预览输出会显示不匹配原因。
- 交付前审查补齐循环后代的父聊天跳过、按 UUID 关联的记忆任务恢复和名称索引冲突检查，均先复现失败后修复。

## 可选直接删除

用户要求支持跳过备份。新增 `prune --no-backup`，保留清单确认、资格复查、父子范围核对和删除结果验证。与 `--backup-dir` 互斥，默认仍备份。直接删除只保存内存进度，失败信息返回已确认删除的 ID，且无法从本工具恢复。增加无备份成功、失败、预览、参数冲突测试，并在原生隔离测试中验证直接删除。
